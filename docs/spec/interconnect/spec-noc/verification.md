## 2. 复现入口

```sh
.venv/bin/python tools/noc_spec.py
make noc-spec-check
make noc-g0-test
make gem-build
.venv/bin/python tools/gtest.py --no-build
.venv/bin/python tools/noc_spec.py --check --gate G1
```

检查命令逐字节对比生成物。`noc-g0-test` 在所有工具测试通过后输出
`build/noc-g0/report.json`，报告包含档案、生成器、测试脚本及依赖文件摘要。

## 4. 预算核对

1 GHz、512 位含报头链路的完整 64 B 数据包占两拍，单方向载荷上界
32 GB/s，四个 Memory Tile 边界合计 128 GB/s。当前 DRAM 的名义引脚
理想值为 134.928 GB/s，原生分段 burst、刷新和控制器调度继续单列。

参考存储合计 404731 B，含数据、描述符、状态、权限及指针。
DDR 所属数据 FIFO 4096 B、描述符参考预算 2048 B、指针同步 48 B 独立核算。
有向路由器线量 39520 bit，本地双向线量 22880 bit，综合面积和物理布线
由后续实现核验。

八跳单播 64 B 读写的 Mesh 与 NI 往返为 74 ns。PCIe 源的无竞争参考合计
369.592 ns，由源 CDC 30 ns、Mesh/NI 74 ns、DDR CDC 15.592 ns 及
固定 250 ns 目标服务相加得到。1 µs 目标另要求正常稳定时钟、目标就绪和
上游持续接收。25 MHz 敏感性场景的同一 Mesh 与 NI 包络为 2.96 µs。

按固定 369.592 ns 驻留计算，64 槽的供给速率为约 11.082 GB/s。
当前 HDMA 每父请求 64 B、16 个父事务对应约 2.771 GB/s 的同条件示例。
这些值用于驻留敏感性分析，实际吞吐上界需要实际平均驻留时间或最小驻留证明。

## 5. 参考选择与独立验收

在已批准的拓扑和容量外，本轮细化每端两周期 NI、16 B 路由/CDC 描述符、
64 B 父描述符、32 B 来源状态及 256 B NI 控制状态预算。
每个 Compute NI 的管理 SRAM 开放区间取八项，执行区间的八项引用地址规格。
这些条目在共享档案中逐项标为参考设计，G1/G2 检验周期与资源使用。

完整包 NI 的 128 B 槽通过两存储 flit 信用预留，短包仍按真实线上长度传输。
大父请求采用有限子槽逐片握手，接受片结果后释放子槽，父终态在全部片收尾后
产生。执行中部分拒绝带已知部分效果，FAULT 保留效果未知语义。

G0 已完成。G1 周期模型、G2 系统接入、G3 生命周期与性能验收分别保持独立状态。
当前 FR-FCFS 的最坏服务上界待证明。5 µs 服务期限与 50 µs 隔离期限按各自
计时边界和流量条件继续验收。
