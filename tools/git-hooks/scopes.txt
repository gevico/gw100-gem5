# ---- 架构与规格（单一真源待重建）

# ---- gem5 模型（gem5-ext/）
func-core     gem5-ext/func-core：数值规则、指令编解码、地址换算、运算核心
ct-sram       Compute Tile 的 SRAM
ct-sync       Compute Tile 的同步单元
ct-ve         向量引擎
ct-me         矩阵引擎
ct-dma        Compute Tile 的 DMA
ct-ctrl       Tile 控制器
mgmt          管理 Tile、派发器
mem-tile      Memory Tile：DRAM 控制器与 DRAM 时序
noc           片上网络
pcie          PCIe Tile 与 Host 通路
common        gem5-ext/src/common 下的公共件
configs       gem5-ext/configs：芯片搭建与运行脚本

# ---- 文档与资料
docs          仓库级文档：README、CLAUDE.md、CONTRIBUTING.md 等
spec-NNN      某一份 SPEC，例如 spec-110
man-NNN       某一份手册，例如 man-060
doc-NNN       某一份总体文档，例如 doc-001
adr-NNN       某一条架构决策记录
reference     reference/ 子模块指针；资料本身在 gevico/gw100-references
tools         tools/ 下的其他工具，例如 tools/templates/ 的文件头模板

# ---- 工程
treewide      横跨整个仓库的机械性改动，例如统一补文件头、统一格式化；只用于不改变行为的提交
build         构建系统、依赖
gem5          gem5 子模块指针与 gem5-ext/patches/
git           仓库配置、钩子、.gitignore、.gitattributes
